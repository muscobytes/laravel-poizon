# 0001. Поддержка синхронизации каталога Poizon

## Цель

Обеспечить приложению каталога full/backfill/incremental-чтения, описания и проверку цен через публичный SDK, без собственного транспорта и подписи. Готовность подтверждена совместимым опубликованным выпуском v0.1.1; для новых возможностей использовать Composer constraint ^0.1.1.

## Происхождение и порядок выполнения

Отображение: задача №01 бэклога → задача 05 проекта 0001. Её исследования выделены в задачи 01–04, публикация — в 06. Номера 01 бэклога и 01 проекта имеют разные пространства нумерации.

Все спайки приняты. Спайк 03 принят с ограничениями по решению владельца 28.11.2026: отдельное чтение цен, отсутствие гарантий цен через modifyTime и автоматического снятия. Неизвестные правила не считаются доказанными; [уточнение в бэклоге](../0000-backlog/tasks/02-confirm-price-and-delisting-contract.md) не блокирует 05/06.

## Отчёты спайков и выпуска

- [01. Временные окна](./reports/01-time-windows.md): принят; включительные границы и разбиение стабильных наборов.
- [02. Размеры страниц и пагинация](./reports/02-pagination.md): принят; пределы, defaults, курсор по id и завершение пустой страницей.
- [03. Цены и снятие SKU](./reports/03-prices-and-delisting.md): принят с консервативными ограничениями; надёжный механизм снятия и ценовые/статусные события в incremental не подтверждены. В отчёте подготовлен запрос Poizon на китайском с русским переводом; не отправлен.
- [04. Fast/Global и форматы](./reports/04-channels-and-responses.md): принят; обе авторизации, описания и совместимость DTO.

- [06. Выпуск v0.1.1 и установка](./reports/06-release.md): принят; локальная и Packagist-установка на PHP 8.2/8.4, GitHub Actions успешен.

Все отчёты разделяют живые наблюдения протокола, документированные сведения и синтетические проверки SDK. Каждую из задач 01–04 выполняла отдельная свежая сессия агента. Во время спайков продуктовый код не менялся. Задача 05 реализована в отдельной свежей сессии и принята: строгая валидация новых параметров, совместимый приём числового distSpuId, 106 тестов / 537 проверок на каждой PHP 8.2 и 8.4. Задача 06 завершена: v0.1.1 опубликован и установлен с Packagist на PHP 8.2/8.4 без VCS-настроек. Проект пакета завершён; открытое уточнение Poizon остаётся в общем бэклоге и не меняет результаты выпуска. Результаты и ограничения опубликованы в [документации пакета](../catalog-sync.md).
