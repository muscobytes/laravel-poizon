# Изменения

Версии следуют Semantic Versioning. До 1.0 несовместимые изменения повышают minor-версию.

## 0.1.2 — 2026-11-28

- Добавлена поддержка Laravel 13 с PHP 8.3+; поддержка Laravel 12 с PHP 8.2+ сохранена.
- Диапазоны Illuminate расширены до `^12.0 || ^13.0`, Testbench — до `^10.0 || ^11.0`.
- CI проверяет обе версии Laravel, включая установку пакета, auto-discovery, публикацию конфига, миграции и `config:cache` в чистом приложении. Smoke-сценарий принимает `LARAVEL_VERSION=12|13` и сверяет установленную версию framework.

## 0.1.1 — 2026-11-28

- Добавлены `querySku`, `modifyStartTime` и `modifyEndTime` в `SpuListQuery`, временные границы — в `SkuListQuery`. Новые параметры одинаково валидируются конструктором и `fromArray()`, `false` сохраняется, `null` исключается из запроса.
- `Spu::fromArray()` дополнительно принимает неотрицательный числовой `distSpuId` и возвращает точную строку; существующие строковые ID сохраняют прежнее поведение.
- Документированы проверенные размеры страниц, курсор по `id`, включительные временные окна, Fast/Global и отдельное чтение цен. Полнота ценовых событий через `modifyTime` и обнаружение снятых SKU не гарантируются; отсутствие предложения не считается удалением.
- Добавлены очищенные HTTP-фикстуры, регрессии и проверка установки опубликованной версии в чистое Laravel 12 приложение. Существующие вызовы, транспорт, подпись, OAuth и пределы прежней локальной валидации сохранены.

## 0.1.0 — 2026-11-24

- Первый самостоятельный выпуск SDK для Laravel 12 / PHP 8.2+.
- Composer-имя: `muscobytes/laravel-poizon`; namespace: `Muscobytes\Poizon`.
- Перенесены типизированный API, OAuth, миграция и 30 тестовых методов из встроенного пакета `raketa/laravel-poizon`. Поведение протокола сохранено.
- Добавлены MIT, Laravel Pint и GitHub Actions.
